📌 Project Overview

The Amazon Sales Analysis Dashboard is an interactive data visualization project designed to analyze Amazon product sales performance. It provides meaningful insights into total revenue, orders, customer behavior, product performance, and country-wise sales distribution.

The dashboard helps users understand sales trends and make data-driven business decisions through interactive visualizations and filters.

🎯 Project Objectives

Analyze overall sales performance.

Monitor total revenue and order trends.

Identify top-performing products.

Analyze country-wise revenue distribution.

Understand customer purchasing behavior.

Explore monthly revenue trends.

Support data-driven business decisions.

📈 Dashboard KPIs

The dashboard highlights the following key performance indicators:

Total Orders: 20K

Average Order Revenue: 559.96

Total Quantity: 375

Total Customers: 4K

Total Revenue: $11.17M

📊 Dashboard Features

1. Sales Trend Analysis

Monthly revenue analysis.

Identification of sales trends over time.

Revenue growth monitoring.

2. Product Performance Analysis

Revenue by product description.

Identification of top-selling products.

Product-wise revenue comparison.

3. Customer Analysis

Revenue distribution by customer ID.

Customer purchasing behavior analysis.

4. Country-wise Sales Analysis

Total revenue by country.

Country-wise order distribution.

Geographical sales performance using a map visualization.

5. Interactive Filters

Users can dynamically filter the dashboard using:

Country

Product Description

Stock Code
